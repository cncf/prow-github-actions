# v3.2.0

Prow can now run as a **GitHub App** (beta) as well as a GitHub Action, and the action picks up
six weeks of features and fixes. Nothing changes for existing action installs: `@v3` callers get
it automatically, `@v3.0.1` pins move to `@v3.2.0`.

## GitHub App (beta)

The same `/commands`, OWNERS, labelling and merging code receives webhooks instead of running in a
workflow: one install per organization, no workflow file, fork pull requests are first class, and
the App's writes trigger your workflows (`GITHUB_TOKEN`'s do not). Deploy it as a container or on
Cloudflare Workers; scheduled jobs run for every installation; `/label-sync` stands in for the
*Run workflow* button. Details, permissions and limits: [Running as a GitHub App](../github-app.md).

Internally the handlers now reach the runtime through a `Platform` interface with a per-event
`RunState`, which the action adapter implements on `@actions/core`. The action's behaviour is
unchanged and its bundle is verified byte-equivalent by the end-to-end suite.

## Features (action and App)

- **GitHub teams in OWNERS** — `approvers`/`reviewers` may list `"@org/team"` ([docs](../commands.md#github-groups)).
- **`blunderbuss.delay`** — wait before requesting reviewers; request only if nobody has yet ([docs](../configuration.md#blunderbuss)).
- **`approve.github_review`** (opt in) — mirror the `approved` label as a GitHub review.
- **`authorization` policy** (opt in) — who may run label, hold, close and review commands.
- **`/label-sync`** — collaborators run the label-sync job from a comment. In the default command list.

## Fixes

- `/meow` matches case-insensitively like every other command.
- A 0-byte OWNERS file lists nobody; a comment-only `prow.yaml` is an empty configuration.
- A label command names the refused values instead of saying "command args missing".
- The `lgtm` job keeps evaluating the remaining pull requests when one evaluation fails.
- A comment without a body carries no commands; a command on a payload without an issue or pull
  number prints the payload, not `[object Object]`.

## Upgrading

Nothing to do for the action. To try the App, see [github-app.md](../github-app.md) and treat it
as beta: the deployment story is settling and feedback is welcome.
