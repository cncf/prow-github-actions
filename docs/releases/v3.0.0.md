# v3.0.0

Prow parity for the interactions a repository has with its contributors: the `/commands`, the
label families, `needs-*` rules, reviewers and approval from OWNERS files, `lgtm` bound to the
reviewed commit, event-driven merging and merge queues. One reusable workflow installs the whole
bot; an organization ships it as a workflow template and configures every repository from one
`prow.yaml` ([Prow for your organization](https://github.com/cncf/prow-github-actions/blob/main/docs/prow-for-your-org.md)).
It replaces the labeler that ran in `cncf/automation`.

## Breaking changes

Change | Since | What to do
--- | --- | ---

`jobs: pr-labeler` removed; it fails with `could not execute pr-labeler. May not be supported`. | #143 | Use [`actions/labeler`](https://github.com/actions/labeler) on `pull_request_target` ([example](https://github.com/cncf/prow-github-actions/blob/main/docs/examples.md#pr-labeler)).
Label commands apply only labels the repository has; a missing label fails the whole request (`/remove-*` is not gated). | #145 | Run the `label-sync` job once (*Actions → Prow → Run workflow*), or create the labels by hand.
Configuration file is `prow.yaml` (`.github/prow.yaml`, or `prow.yaml` in the organization's `.project`/`.github` repository); the organization tier now applies to every repository. Legacy `.prowlabels.yaml` is still read. | #144 | Nothing for a repository with only `.prowlabels.yaml`. Check what your `<org>/.github` `prow.yaml`, if any, adds ([configuration](https://github.com/cncf/prow-github-actions/blob/main/docs/configuration.md)).
`/hold` applies `do-not-merge/hold`. The merge gate's `missing_labels` default is `do-not-merge/*`, `needs-rebase`, `hold`; the legacy `hold` still blocks and cancel removes both. | #154 | `label-sync` creates `do-not-merge/hold`. Keep the old name with `hold: { label: hold }` ([upgrading from `hold`](https://github.com/cncf/prow-github-actions/blob/main/docs/automatic-merging.md#upgrading-from-the-hold-label)).
Repositories with OWNERS files: `/approve` is aggregated coverage. It records the commenter's approval instead of submitting a bot review, `approved` is applied once every changed file is covered, the merge gate becomes `lgtm` **and** `approved`, and `/approve` needs an approver for **at least one** changed file (was: every file). Repositories without OWNERS files are unchanged. | #156 | `label-sync` creates `approved`. Branch protection that counted the bot's review needs a human review or the gate instead. `tide: { labels: [lgtm] }` keeps the old gate ([upgrading to aggregated approval](https://github.com/cncf/prow-github-actions/blob/main/docs/automatic-merging.md#upgrading-to-aggregated-approval)).
`lgtm` is bound to the reviewed commit through the `prow/lgtm` commit status and never merges commits pushed after it. **`statuses: write` is required**; without it `/lgtm` fails and applies no label. `lgtm` labels present at upgrade time are unbound: the next evaluation strips them once, with a comment. | #163 | Grant `statuses: write`, or set `lgtm: { bind_to_commit: false }`. Re-apply with `/lgtm` ([upgrading to the bound `lgtm`](https://github.com/cncf/prow-github-actions/blob/main/docs/automatic-merging.md#upgrading-to-the-bound-lgtm)).
The `lgtm` cron reads `mergeable_state` and skips `blocked`, `unstable`, `behind`, `dirty` and `unknown` pull requests instead of sending a merge GitHub refuses. A merge GitHub does refuse fails the run. | #142, #163 | Nothing; a skipped PR is logged with its state.
`/retest`, `/test` and `/ok-to-test` are in the default command set and need **`actions: write`**. | #164 | Grant `actions: write`, or set `prow-commands` without them.
Commands and keywords are case-insensitive. The author cannot `/lgtm` their own pull request (the bot replies, the run fails); `/lgtm cancel` by the author still works. | #136 | Nothing.
`/label` and `/remove-label` refuse `lgtm`, `approved`, `hold`, `do-not-merge/*` and `hold.label`, even when listed. | #142 | Use `/lgtm`, `/approve`, `/hold`.
`merge-method` input: `tide.merge_method` in `prow.yaml` wins over it, and on a branch that requires a merge queue the queue's method wins. | #144, #166 | Move the setting to `prow.yaml` if both are set.
New inputs `dry-run`, `config`, `cat-api-key`; `jobs` accepts `sweep` and `label-sync`. | #104, #144, #145, #163 | Nothing; every input stays optional.

## Permissions

The caller grants, and the reusable workflow asks for exactly:

```yaml
permissions:
  contents: write
  issues: write
  pull-requests: write
  statuses: write
  actions: write
```

Scope | For
--- | ---
`contents: write` | merging; reading OWNERS and `prow.yaml`
`issues: write`, `pull-requests: write` | labels, comments, assignees, review requests
`statuses: write` | the `prow/lgtm` commit status that binds `lgtm` to the reviewed commit
`actions: write` | `/retest`, `/test`, `/ok-to-test` re-running and approving workflow runs

## Upgrading from v2

1. Grant `statuses: write` and `actions: write` next to the permissions you already had, or opt
   out with `lgtm: { bind_to_commit: false }` and a `prow-commands` list without `/retest`,
   `/test`, `/ok-to-test`.
2. Run the `label-sync` job once (*Actions → Prow → Run workflow* with the reusable workflow, or
   `jobs: label-sync` on `workflow_dispatch`): it creates `do-not-merge/hold`, `approved`,
   `ok-to-test` and every label the configuration describes.
3. Expect open pull requests carrying `lgtm` to lose it once, with a comment; re-apply with
   `/lgtm` on the reviewed commit.
4. Repositories with OWNERS files: open pull requests need `/approve` (or an approving review)
   from an approver of the changed files before they merge; `tide: { labels: [lgtm] }` keeps the
   old gate.
5. Pull requests held with the legacy `hold` label keep blocking; new holds are `do-not-merge/hold`.
6. Replace `cncf/prow-github-actions@v2` with `@v3.0.0` (what the templates ship) or the floating
   `@v3`; or switch to the reusable workflow, `cncf/prow-github-actions/.github/workflows/prow.yml@v3.0.0`.

Details: [upgrading](https://github.com/cncf/prow-github-actions/blob/main/docs/installing.md#upgrading),
[the bound `lgtm`](https://github.com/cncf/prow-github-actions/blob/main/docs/automatic-merging.md#upgrading-to-the-bound-lgtm),
